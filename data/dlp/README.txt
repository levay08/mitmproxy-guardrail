Rule data for the guardrail. Text and name lists only; no code copied from these projects.

  gitleaks.json         rules from gitleaks (MIT)          https://github.com/gitleaks/gitleaks
  testpattern.json      rules from TestPattern (MIT)       https://github.com/testpatterndev/patterns
  privacy-mask.json     rules from privacy-mask (MIT)      https://github.com/fullstackcrew-alpha/privacy-mask
  places.txt            place names from GeoNames (CC-BY-4.0)  https://geonames.org
  postal.txt            postal codes, cahyadsn/wilayah_kodepos (MIT), based on Kepmendagri 2025

GeoNames data is CC-BY-4.0 and needs attribution; this file is that notice.
Download hashes of the source archives are kept with the working notes, not here.
